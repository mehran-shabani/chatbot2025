# پروژه چت‌بات هوش مصنوعی برای پژوهشگران فارسی‌زبان

این پروژه یک چت‌بات هوش مصنوعی تجاری (SaaS) است که برای کمک به پژوهشگران فارسی‌زبان طراحی شده است. رابط کاربری (UI) و تجربه کاربری (UX) کاملاً به زبان فارسی می‌باشد.

## پشته فناوری (Technology Stack)

- **فرانت‌اند:** Next.js (همراه با TypeScript, Tailwind CSS, ESLint)
- **بک‌اند:** FastAPI (بر پایه Python)
- **پایگاه داده اصلی:** PostgreSQL
- **مدیریت مهاجرت‌های پایگاه داده:** Alembic
- **پایگاه داده برداری:** ChromaDB
- **صف وظایف:** Celery (همراه با Redis)
- **هوش مصنوعی:** کتابخانه OpenAI
- **احراز هویت:** سیستم بدون رمز عبور از طریق ارسال کد یکبار مصرف (OTP) با سرویس کاوه نگار.
- **درگاه پرداخت:** بیت‌پی ایران (bitpay.ir)

برای جزئیات بیشتر در مورد معماری، نقشه راه و دستورالعمل‌های توسعه، به فایل [AGENTS.md](AGENTS.md) مراجعه کنید.
